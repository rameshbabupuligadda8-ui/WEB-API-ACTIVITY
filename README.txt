COMBINED WEBPAGES PACKAGE
=========================

Contents
--------
1. combined_webpages.html
   The combined viewer containing all three supplied webpages:
   - My Personal Portfolio (web 1.html)
   - Aura - Modern E-Commerce (web 6.html)
   - Foodie's Cafe (web 8.html)

   Open this file in a modern browser. Use the tabs at the top to switch
   between the three websites. Each website is embedded separately to
   preserve its original styling and JavaScript behavior.

2. combined_webpages_code.txt
   The complete source code for the combined viewer HTML file.

3. screenshots/
   Contains one combined screenshot image showing previews of all three
   webpages side by side.

How to use
----------
- Extract the ZIP file.
- Open combined_webpages.html in Chrome, Edge, Firefox, or another modern browser.
- Select a tab to view each website.

Notes
-----
- The AURA e-commerce webpage uses Tailwind CSS and Font Awesome from CDNs,
  and product images from Unsplash. An internet connection may be required
  for those external assets.
- The original HTML files are embedded as provided. Any issues already
  present in the source webpages may also remain.
- The screenshot is a visual preview collage, not a live browser capture.
